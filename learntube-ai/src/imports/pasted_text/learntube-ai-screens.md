Design ONLY these 3 screens for the existing **LearnTube AI** product:

1. Landing / Home Page
2. Sign Up Page
3. Login Page

Do NOT redesign, modify, or create any other screens. The rest of the product is already designed.

## Product Context

LearnTube AI is an intelligent learning agent that transforms YouTube educational videos into personalized interactive learning experiences.

Core experience:

YouTube Video → AI Understanding → AI Tutor → Quiz → Learning Gaps → Personalized Review

The product should feel like a **modern AI-powered education platform**, not a generic chatbot and not a generic SaaS dashboard.

Target users: students and self-learners.

---

# 1. LANDING PAGE

Create a polished, premium SaaS-style landing page.

### Hero

Main headline:

**Turn YouTube Videos Into Your Personal AI Tutor**

Supporting text:

**Learn, ask questions, test yourself, and discover what you need to improve — all from one video.**

Primary input:

* Large rounded input
* Placeholder: **Paste a YouTube video or playlist URL**
* Primary button: **Start Learning**

Secondary action:
**Try a Demo**

The demo should communicate that users can immediately experience the product without searching for a video themselves.

### Hero Visual

Create a strong visual representation of the LearnTube AI workflow.

Show a YouTube learning video transforming into:

Video → AI Tutor → Quiz → Learning Insights

Use subtle AI/education visual elements such as:

* video thumbnail
* AI processing indicator
* tutor response
* quiz card
* progress/learning insight

Keep it clean and sophisticated. Do NOT make the page visually overloaded.

### How It Works

Create a simple 4-step section:

**1. Add a Video**
Paste a YouTube video or playlist.

**2. AI Understands**
LearnTube AI analyzes the educational content.

**3. Learn Interactively**
Ask questions, learn concepts, and use Teach Me mode.

**4. Test & Improve**
Take adaptive quizzes and discover learning gaps.

### Feature Highlight

Do NOT create 13 separate feature cards.

Instead, highlight the core value through 3–4 strong sections:

**AI Tutor**
Ask questions about the actual video and receive grounded answers with timestamps.

**Learn by Segment**
Select a section of the video and let AI teach that specific topic.

**Test Your Understanding**
Generate quizzes based on what you actually watched.

**Know What You Don't Know**
AI identifies weak concepts and recommends what to review.

### Trust / Grounding

Add a subtle trust section communicating:

**AI grounded in your learning content**

Supporting message:

LearnTube AI answers based on the video transcript and provides timestamps so students can verify where the information came from.

Use a small label such as:

**✓ Based on this video**

Do not make this section overly technical.

### Footer

Simple professional footer:

LearnTube AI

"Learn smarter from the content you already watch."

Include minimal navigation links:

* Home
* My Learning
* About

# VISUAL DESIGN SYSTEM

Create a professional color system specifically for LearnTube AI.

The design should feel:

* Modern
* Intelligent
* Educational
* Trustworthy
* Premium
* Calm
* Technology-focused

Avoid:

* overly bright children's education colors
* excessive gradients
* excessive neon
* generic purple AI aesthetics
* overly dark cyberpunk styling

Use a sophisticated primary color with neutral backgrounds and one accent color.

Suggested direction:

* Deep navy / blue-based primary
* Clean white or very light neutral backgrounds
* Blue/cyan accent for AI-related elements
* Dark charcoal text
* Soft gray borders
* Very subtle gradient accents only where useful

Maintain strong accessibility and contrast.

---

# COMPONENT STYLE

Use a consistent modern design system:

* Rounded cards
* Medium border radius
* Soft shadows
* Clean spacing
* Large readable typography
* Clear hierarchy
* Professional buttons
* Minimal icons
* Lucide-style icons
* Consistent input fields
* Clear hover/focus states

Typography should feel modern and highly readable.

Use generous whitespace.

Do not make everything rounded like a children's app.

# IMPORTANT DESIGN RULES

1. ONLY design Landing, Sign Up, and Login.
2. Do NOT redesign any existing LearnTube AI screens.
3. Maintain a visual system that can naturally match the existing screens.
4. Do not add unrelated features.
5. Do not create unnecessary dashboard components.
6. Keep the UI production-ready rather than concept-art style.
7. Make the product look like a serious startup/hackathon product.
8. Prioritize usability and clarity over decorative visuals.
9. Authentication should clearly explain the benefit of creating an account: persistent learning progress.
10. Make the Landing Page strong enough that a hackathon judge understands the product within 5–10 seconds.

Final visual story:

**YouTube Content → LearnTube AI → Personal AI Tutor → Quiz → Learning Progress**

Create polished, developer-friendly designs with reusable components and consistent spacing, typography, colors, buttons, inputs, cards, and states.
